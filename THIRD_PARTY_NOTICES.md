# Third-party materials

## Reference and media

The project is inspired by [GreatStack's MERN E-commerce App](https://greatstack.dev/p/E-commerce-mern-app) and its linked [Shopper tutorial](https://www.youtube.com/watch?v=y99YgaQjgx4).

The 36 product photographs and two promotional images in `public/images` are optimized derivatives of the public asset archive linked from that project page. The source files were converted to WebP and product names/descriptions were independently written as demonstration copy. Neither the product photographs nor any depicted brands/models are claimed as original work by the developer.

The linked archive did not supply a separate media license in the downloaded files. The MIT license in this repository applies to the independently implemented code and documentation, **not** the reference media. Retain attribution for portfolio/educational use and obtain appropriate media permissions or replace the imagery before commercial distribution. No paid GreatStack source code is included.

## Open-source dependencies

React, Vite, Tailwind CSS, TanStack Query, React Router, Zod, TypeScript and Vitest retain their respective licenses. Lucide icons retain their ISC license. Dependency versions are recorded in package-lock.json. No backend or MongoDB binaries are included.
